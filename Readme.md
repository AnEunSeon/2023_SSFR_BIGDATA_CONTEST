# 자동차보험 고객 사고율 예측

### 1. 데이터 전처리

- 활용 데이터: 보험사 자동차보험 고객 정보 데이터
- EDA
    - 스피어만 상관관계 분석
    - 사고율 분포 시각화
- 이상치 제거 및 변수 제거
- 자료형 변환: Ordinal Encoding, Label Encoding, One-hot Encoding 진행

### 2. 로지스틱 회귀 분석

- 예측에 활용할 변수 선택 및 저위험군, 고위험군 고객 분류
    - VIF를 통해 변수 간 다중공선성 확인
    - 로지스틱 회귀 분석 결과의 변수 유의성 확인
- 클래스 불균형으로 인해 정확도가 높지 않은 한계가 존재

### 3. 앙상블 분석, 머신러닝 모델링

- 사고율 예측 회귀 트리 모델 학습
    - 분포 가정이 필요하지 않고, 결과에 대한 해석이 용이하기 때문
    - Gradient Boosting, Decision Tree, Random forest 회귀 트리 모델들로 예측 모델 학습
    - Voting 방법을 사용하여 각 회귀 트리 모델의 예측값의 평균을 최종 예측값으로 활용
- 예측 결과 해석
    - Feature Importance, SHAP Value를 통해 예측에 영향을 미친 변수와 고객의 사고 요인을 분석

### 4. 결론

- 자동차보험 관련 선제 대응 방안 제안
    - 고객 정보와 사고율 예측 결과를 종합한 고객 대시보드를 통해 고객 세분화 및 보험 인수 심사 강화
    - 사고율이 낮은 우량 고객의 특징을 파악하여 할인 특약 상품 기획에 활용
